# DigitalCircuitTest
Here I want to test some tools for creating digital circuits. 
The goal is to design some usefull digital circuit using Verilog, go through the design process using [LibreLane](https://librelane.readthedocs.io/en/latest/index.html), and then use [TinyTapeout](https://tinytapeout.com/teaching/) to produce the circuit.
